# 도서 API 선택 결정

- 결정일: 2026-10-30
- 상태: 확정
- 프로덕션 적용 범위: 별도 구현 단계에서 진행

## 최종 선택

밑줄의 도서 데이터는 **카카오 책 검색 API와 도서관 정보나루 API를 함께 사용**한다.

| 기능 | 담당 API |
|---|---|
| 제목·저자·ISBN 검색 | 카카오 책 검색 |
| 검색 결과 기본 메타데이터 | 카카오 책 검색 |
| 인기 도서 | 정보나루 인기대출도서 |
| 요즘 뜨는 책 | 정보나루 대출 급상승 도서 |
| ISBN 상세·책소개 보완 | 정보나루 |
| 전체 페이지 수 | API 자동 입력 없이 기존 사용자 입력 유지 |

검색 화면에서는 카카오만 호출한다. 정보나루 상세 조회는 사용자가 도서를 선택한 뒤 ISBN13을 기준으로 필요한 경우에만 호출한다. 목록 화면은 정보나루의 인기대출도서와 대출 급상승 API를 사용한다.

## 검증 근거

동일한 국내 도서 25권과 그중 최근 2년 도서 15권으로 비교했다. 검색 성공은 유사 제목이 아니라 기대 ISBN13의 목표 판본이 결과에 포함되는지를 기준으로 했다.

### 카카오 책 검색

| 지표 | 결과 |
|---|---:|
| 제목 검색 Top 50 | 24/25 (96%) |
| 저자 검색 Top 50 | 24/25 (96%) |
| ISBN 검색 Top 50 | 25/25 (100%) |
| 최근 2년 제목 검색 | 15/15 (100%) |
| 최근 2년 저자 검색 | 14/15 (93.33%) |
| 최근 2년 ISBN 검색 | 15/15 (100%) |
| 검색 시도 오류율 | 0% |
| 표지 실제 로딩 | 25/25 |
| 3배율 책장 표지 해상도 충족 | 0/25 |

카카오는 검색 정확도와 최신 판본 검색에서 합격 기준을 만족했다. 표지는 모두 폭 120px로 해상도가 부족하고 전체 페이지 수는 제공하지 않는다.

### 도서관 정보나루

| 지표 | 결과 |
|---|---:|
| 제목 검색 | 18/25 (72%) |
| 저자 검색 | 19/25 (76%) |
| ISBN 검색 | 20/25 (80%) |
| ISBN 상세 조회 | 25/25 (100%) |
| 책소개 제공 | 22/25 (88%) |
| 표지 실제 로딩 | 25/25 |
| 3배율 책장 표지 해상도 충족 | 1/25 |
| API 오류율 | 0% |

정보나루는 메인 검색에는 부족하지만 ISBN 상세 조회와 대출 기반 목록 API에 적합하다.

## 제외한 후보

### 국립중앙도서관 ISBN 서지정보

- 제목 검색 23/25, 저자 검색 19/25로 메인 검색 합격 기준 미달
- 표지와 책소개는 각각 2/25만 제공
- 페이지 수는 20/25 제공했지만 독립 정답 정확도 검증이 완료되지 않음
- 검색·표지·상세 데이터를 함께 담당하는 소스로는 부족하여 제외

### Google Books

- ISBN13 정확 조회 0/25
- 최근 2년 ISBN13 정확 조회 0/15
- 페이지 수와 표지 모두 0/25
- 모든 요청은 API 오류 없이 `totalItems: 0`을 반환
- 국내 판본 보완 소스로 사용할 수 없어 제외

## 알려진 한계

- 두 API 모두 3배율 책장에 충분한 고해상도 표지를 안정적으로 제공하지 않는다.
- 두 API 모두 전체 페이지 수를 제공하지 않으므로 기존 사용자 입력을 유지한다.
- 카카오·정보나루 간 메타데이터가 다르면 검색 결과에서는 카카오 값을 우선하고, 정보나루는 누락 필드만 보완한다.
- 도서 판본 식별과 API 간 데이터 결합의 기준키는 ISBN13이다.

## 유지하는 검증 자산

- `Tools/Data4LibraryValidation/Sources/Data4LibraryValidation`: 정보나루 회귀 검증
- `Tools/Data4LibraryValidation/Sources/KakaoBookValidation`: 카카오 회귀 검증
- `Tools/Data4LibraryValidation/Sources/ValidationCore`: 공통 측정 로직
- `Tools/Data4LibraryValidation/Sources/Data4LibraryValidation/Resources/books.json`: 공통 25권 표본

탈락한 후보의 실행 코드와 생성 보고서는 저장소에서 유지하지 않는다. 필요한 선택 근거는 이 문서를 기준으로 한다.
